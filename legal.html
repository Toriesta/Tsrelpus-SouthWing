规则与合规

这一页只写三件事：内容的边界、投诉与下架的流程、你的数据存在哪里。 看完还有疑问，按第 04 节的渠道提，不必先打招呼。

01站点性质

《天枢南翼》是非官方民间记录站点，不是新闻单位，不具有新闻采编资质， 不从事新闻采编发布活动，不做采访，不发布自行采写的新闻。

站内内容是公开信息的整理与转录：政府公告、主管部门公示、公开报道、招聘与租房挂牌页。 每条尽量给出原文出处与日期，原文自相矛盾时照录并注明，不替它抹平。 本刊与泉州市、晋江市、南安市政府及各镇、各园区、各企业没有隶属或合作关系。

页面上没有统计。站内不装访客统计，文章页也不显示阅读量与点赞数； 哪一条看得人多，本刊自己也不知道，所以不拿这类数字说话。

02内容红线：不登什么

下面八类，无论来源多热、传播多快，一律不发；已发的，发现即下架。

  1. 未经核实的指控。没有可点开的原文、没有主管部门结论的点名举报、「网传」「听说」「朋友说」，不发。
  2. 可识别个人的信息。身份证号、手机号、门牌号、车牌、病历、学籍、银行卡，以及「姓名 + 单位 + 住址」这类可拼出个人的组合，不发。
  3. 未成年人。不写姓名、不拍正脸、不写学校与班级。涉未成年人的纠纷只写处理结果。
  4. 性侵、自杀、自残。不写过程细节，不推测动机，不转述现场描述。
  5. 未决刑事案件。只照录官方通报原文，一律用「涉嫌」；不作定性，不代替法院下判词。
  6. 私彩与赌博。六合彩栏只登已开奖号码，不写预测、不画玄机、不卖特码、不给下注入口；任何赌博推广一律不发。
  7. 明星娱乐八卦与饭圈互撕。超出泉州南翼十镇范围的，不发。
  8. 广告与导流。二维码、拉群、报价、联系方式、软文，一律不发；本刊不接广告。

04侵权投诉与下架

如果你认为站内某条内容侵犯了你的名誉权、隐私权、肖像权、著作权或其他合法权益， 请按下面的方式提出。我们承诺：收到符合要求的投诉后，24 小时内先行隐藏涉事内容，再作核实。 先把内容撤下来，再谈对不对。

投诉渠道（二选一）：
① 邮箱 toriesta@qq.com，主题以 [投诉] 开头——涉及个人隐私、身份材料的走这条，不公开；
② 在本仓库提交 Issue，标题以 [投诉] 开头——需要公开留痕与答复的走这条。
请勿在公开 Issue 里粘贴身份证、住址、电话等材料；邮箱来信同样不必附证件照片，先写清事由，我们会回复具体核验方式。

投诉请包含四项：

  1. 位置：涉事页面的链接，或条目标题与日期。
  2. 权利与理由：涉及哪项权利，具体哪一句失实或侵权，依据是什么（附可点开的链接）。
  3. 身份说明：你是当事人本人、受托代理人，还是权利人；可先作简述。
  4. 诉求：更正、删除、补充回应，或三者兼有。

复制后到 Issue 里粘贴，逐项填写。

处理时限：24 小时内先行隐藏；3 个工作日内给出核实结论。 认定失实的，更正在正文中标注日期并保留原值，不做静默修改； 认定不失实的，书面说明理由；恶意投诉、反复骚扰的，本刊保留追究的权利。

反申诉：被投诉一方可在同一 Issue 下提交说明与证据，双方材料一并呈现，本刊不预设结论。

05隐私说明

本站没有账号系统，不收集姓名与手机号，不接入第三方统计、广告或追踪脚本，也不使用 Cookie 做跨站跟踪。

只在本机保存以下几项，用于记住你的阅读偏好：

  1. 字号与夜间模式的设置（键名 tsui）；
  2. 底部「热点速览」是否被你关闭（tsui_tick）；
  3. 听书的音色、倍速与播放进度（tslisten-*）；
  4. 小说的阅读进度与语速。

以上数据全部存在你自己的浏览器里，不上传、不回传、不与任何第三方共享；清除浏览器数据即全部消失。

本站托管在 GitHub Pages，访问时的 IP、时间、请求路径等服务器日志由 GitHub 按其隐私政策处理，本刊无法读取，也无法定位到具体个人。 本站不使用 CDN 统计、不埋点、不做用户画像。

投稿：你主动提供的文字与图片仅用于发表与存档；你要求匿名、不刊登或不署名的，按你的要求处理。 投稿渠道中产生的聊天记录，在稿件处理完毕后 30 天内删除。
