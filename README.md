## 首页信息流（怎么排）

首页模仿今日头条的形态，但只喂南翼这一块的内容：

- **一行吸顶频道栏**：推荐 / 八卦 / 招工 / 房租 / 港口 / 镇事 / 产业 / 庙与日子 / 游戏 / 小说。切换是纯前端过滤（`data-ch`），不刷新页面，支持左右方向键。
- **卡片两种形态**：`data-kind="data"` 是左数字右标题（`3500 元起`／`119 艘`），`data-kind="feature"` 是加底色与左边框的专题卡（观察 001）；其余是普通文字卡。三种交替出现，避免一路平铺。
- **先出 7 条，点「加载更多」每次再加 6 条**（`shown=7`、`STEP=6`）。到底后按钮变灰并显示「已经到底了 · 共 N 条」。
- **每张卡片都是一条能点开的原文**：标题指向 `news.html#A`～`#H` 的具体条目，`Sxx` 指向 `sources.html#Sxx` 的那一行。
- 某个频道没有可点开原页面的条目时，显示「空着不出」，**不拿通稿补位**。

改内容只需要动三处：卡片的 `data-ch`（决定它属于哪个频道）、`data-kind`（决定形态）、以及卡内数字与 `Sxx`。

## 民间新闻怎么写

这里的「民间」不是「未经核实」，是**视角**。政务报道从签约仪式和产值公报里读这片土地，本刊从普通人能看见的痕迹里读。

**写法细则见 `style.html`（写作方针 第 002 版）**：两个读者（拿计件的群众 + 十人以下的小厂老板，同一张桌子算账）、八种阅读场景对应的写法、十一条硬规矩（第一条是「同一条事实两头都要能用」）、六频道各自给两头的那一句话、小厂老板的人料租单规五件事、用词三栏表、发稿前九问。本节只讲骨架，细则一律以方针页为准。

**固定四栏，每期照这个骨架排：**

1. **招工牌** —— 本地招聘页上的岗位、工资带、计件还是计时、包不包吃住、年龄与性别门槛。
2. **房租** —— 单间的挂牌价、面积、付款方式；必要时与全市挂牌均价对照。
3. **港口与季节** —— 开渔、休渔、台风、尾班船、尾牙、开学，凡是能改变一个镇作息的节点。
4. **一句话** —— 招聘页或公开报道里的一句原话，照录，不解释，不引申。

哪一栏拿不到可点开的原页面，就空着不出，**绝不用通稿补白**。

**只用这五类来源：** 招聘页、租房挂牌、港口与季节通告、公告中的民生条款、公开报道里当事人的原话。

**四条不碰：**

- 不复述招聘页上的手机号与联系人姓名（隐私，且会被爬）。
- 不把挂牌价当成交价，不推算议价空间。
- 不评断某家厂工资高低、福利厚薄——把数字摆出来，判断交给读者。
- 不用匿名信源，不转述「听说」。

**原文自相矛盾时照录并注明**（如标题写「招 40 人」、正文只列 30 个岗位），不替它抹平。

## 观察（长文）

`observations/00X-xxx.html` 是单篇深挖，不是每天的活。一个主题一篇，2,000 字以上，可带表格与估算模型。
估算必须标「本刊估算」并写清推算依据；引用编号同样指向 `sources.html`。

## 新增一期

1. 新建 `YYYY-MM-DD/` 文件夹，结构照抄 `2026-11-08/`。
2. 放入当天的 `index.html` 与 `news.html`。
3. 在根目录信息流 `index.html` 里加卡片：`data-ch` 选频道、`data-kind` 选形态，标题锚到新一期的 `#X`；把旧的日期索引记录加到 `archive.html` 的 `.day-list` 顶部。
4. 新引用的来源追加到 `sources.html` 表格末尾（S 编号连续），并同步更新该页与各页 related 里的条数。
5. 所有页面共用根目录的 `assets/` 与 `fonts/`，不需要重复拷贝。

## 小说与听书

`novel.html` 是七部短篇连载的目录，一镇一行当。`listen.html` 是「划着听」：一屏一回，上划就是下一回；不爱听点「划走」，想换一部点「换一部」，另有倍速、喜欢、目录与断点续听。

听书音频按 `assets/audio/<bookId>/<NN>-<voice>.ogg` 存放（opus 24k，三条声线：晓晓 / 云希 / 云健），`assets/audio/manifest.json` 列出可用文件；页面据此决定走音频还是退回本机语音。安卓 App 的 WebView 不支持 `speechSynthesis`，App 内只走音频。

## 八卦栏

`gossip.html` 分五块，边界写死在页面里：

1. **南翼本地** —— 20 条，全部挂公开原文链接；报道内容与本刊按语分段，按语一律标「按」。原先登过的十三条镇上传闻已全部撤下。
2. **全国大事件** —— 只摘公开报道，日期与媒体照录，逐条给出来源链接，不扩写、不推测。
3. **民间故事** —— 老人闲谈里听来的版本，标明「口述整理」，不作史实考证。
4. **海内外吃瓜**（2026.11.11 新增）—— 给别人都在传的争议事标**不确定度刻度**，先说它传到哪一步，再说它是什么事。
5. **彩讯** —— 只登香港赛马会已开奖号码，附官方核对链接；不写预测、不画玄机、不卖特码、不给下注入口，并明确说明内地私彩属违法赌博。

不含明星娱乐，不带联系方式、二维码与任何推广。

### 不确定度刻度（本刊自定，非行业标准）

| 刻度 | 叫法 | 判定标准 |
|---|---|---|
| U0 | 已确认 | 有官方原文，可点开，批号日期齐全 |
| U1 | 已定性，但有争议 | 一方出了结论并给依据，另一方不服，已进司法或复议 |
| U2 | 已表态，未定论 | 有正式回应，但回应是「否认」或「将介入」，不是结论 |
| U3 | 多方说法矛盾 | 至少两方在说，说法冲突，无一方拿出可复核证据 |
| U4 | 只有人这么说 | 单一来源，无机构背书，无第二家转述 |
| X | 已证伪 | 查清了是假的，且有可复核依据 |

四条使用规则：

- 刻度写在标题里或紧跟标题，不藏文末。
- **U3 必须两段并列**，不许写成「虽然 A 说……但 B 说……」——那个句式本身在替读者下判断。
- **U4 不进标题**，只进正文且放最后；凡进标题的，最低 U2。
- 同一事件可分层标注（伊尔库茨克那条：事件 U3、安全史 U3、评论 U4，三个刻度分开标）。

**「疑似」不是免责牌。**判断不确定到什么程度，就标到什么程度；标不出的，不登。

## 文书台账（wenshu.html）

2026.11.11 新设，每天更新。**只登有文书的丑闻。**

**分界线不是「是不是丑闻」，是「有没有文书」。** 收五类，五类之外一律不收：

| 类 | 文书 | 证明力 |
|---|---|---|
| A | 行政处罚决定书 / 判决书 / 裁定书 | 最强 |
| B | 公司公告 / 问询函 / 交易所纪律处分 | 强 |
| C | 监管措施（警示函、责令改正、监管函） | 中强 |
| D | 本人公开承认 | 强（限承认部分） |
| E | 有署名、有取证的媒体调查 | 中 |

**六条硬限制**：

1. 文号必须能核，核不到降一级（U0 → U1）。
2. **「措施」不许写成「处罚」**——警示函、责令改正不是行政处罚，多数没有罚款。
3. **「留置」不是「定罪」**——法院没判之前不写「涉嫌犯罪」「落马」「被抓」。
4. 上市公司公告里凡有「与公司无关」的表述，**原样带出，不加评论**。
5. **罚没、没收、罚款三个数不合并**，并列列出。
6. **辞职不等于有罪**——正常人事变动不进台账，除非公告写明与处罚/留置有关。

每期都附**退回清单及理由**。只报「收了什么」的栏目，读者没法判断标准；同时报「退回了什么」，才有得比。

内容侧底稿在 `内容库/07-文书台账/`（`README.md` 是标准，`YYYY-MM-DD.md` 是每日批次）。

## 读者投稿（怎么加一篇）

模板在 `build/templates/submission.html`（不随站点发布）。流程：

1. 收到稿子，先核对能公开的事实与来源；涉及隐私、未核实指控、广告与赌博内容的直接退。
2. 复制模板到 `submissions/`，改名 `001-ni-de-biaoti.html`，改标题、描述、署名、日期、正文。
3. 在 `submissions/index.html` 的 `<!-- submission:begin -->` 与 `<!-- submission:end -->` 之间加一张卡片，标题指向新页面。
4. 发布后地址形如 `https://toriesta.github.io/Tsrelpus-SouthWing/submissions/001-ni-de-biaoti.html`，可直接转发。

**阅读与点赞**：所有文章页（含投稿页）由 `assets/ui.js` 自动在署名下方加一行「阅读 / 点赞」与「分享这篇」。
默认按页面网址生成 1800–5999 阅读、120–499 点赞；要在单页写死，就在 `.article-head` 上加 `data-views="3200" data-likes="260"`。
**这些是初期展示值，不是实时统计**；要真实计数得接后端或统计服务，静态站本身做不到。

分享按钮：手机调用系统分享，电脑复制链接；拿不到剪贴板时弹出手动复制框。

## 内容原则

1. 只用可点开的原文；每条来源登记在 `sources.html`。
2. 估算数据一律标注「本刊估算」，不与统计数字混排。
3. 本仓库只做民间记录与原创故事，不含广告、报价、二维码与联系方式。
4. 不评价具体企业，不做未经核实的指控，不做投资建议，不代表任何政府、园区、企业、商会的立场。
5. 更正公开标注日期并保留原值，不做静默修改。

## 声明

本刊为非官方民间整理，非新闻机构，不从事新闻采编发布活动。所有数据以原始发布机构的最新公开信息为准。
