# 南翼故事 · 爽文写法手册（内部）

> 不是给读者看的，是给自己照着写的。看完就删掉也行，但动笔前必须过一遍。

## 一、结论先说

市面上「白手起家创业爽文」能火，靠的不是文笔，是三件事：

1. **前三百字必须出事。** 开场不介绍身世、不交代背景，第一句就是冲突或数字。
2. **爽点按字数配给。** 免费平台口径：300 字一个小看点，500 字一个钩子，1500 字内必须有一次情绪起伏。超过 1500 字没起伏，读者划走。
3. **每个爽点都要「先抑后扬」。** 打压（读者憋屈）→ 反击（拿筹码）→ 公开打脸（围观群众反应）。直接让主角碾压，读者不觉得爽，只觉得无聊。

## 二、结构模板（本书统一用）

| 位置 | 任务 |
|---|---|
| 第 1 回 | 出事。主角被剥夺（辞退/退单/被抢功），末尾留一个「他其实看见了什么」的钩子 |
| 第 2 回 | 反转的第一次兑现：别人失败了，回头找他 |
| 第 3 回 | 公开比试。主角当众用一个外行看不懂的动作（敲三下、摸一把粉、改一个孔）定输赢 |
| 第 4 回 | 从「手艺」升到「算账」：出材率、克重、针距、发泡时间——让读者看到钱是怎么多出来的 |
| 第 5 回 | 大爽 + 留白。拿到股权/客户/名分，最后一句抛下一部的钩子 |

五回，每回 800—1000 字。全书 4000—5000 字，朗读 15—18 分钟，正好一顿饭。

## 三、爽点四类，必须轮换

- **打脸反转**：看不起主角的人当场哑掉。
- **秘密揭露**：假进口料、假 A 级板、假工艺被点破。
- **成长突破**：手艺升级（改模具、调配方、算锯路）。
- **温情反转**：父亲/妻子/徒弟的一句话（每部最多两处，多了腻）。

连着两回用同一类，读者会疲。**打脸 → 揭露 → 突破 → 温情**，按这个顺序错开。

## 四、可复用的六个桥段（已验证有效）

1. **纸条压在玻璃下**：主角走时留下一份「你们会回来找我的证据」，几个月后应验。
2. **敲三下**：外行看不懂的动作定生死（敲石头听暗裂、弹面料听回弹）。
3. **黑板算账**：当着所有人把数字算到小数点后，把「经验」变成「可验证」。
4. **扫二维码的老外**：外商用手机扫一下就知道真假——用外部视角给主角背书。
5. **抢功**：二代/侄子把功劳领走，第三次当着客户面翻车。
6. **最后一句话留白**：不写结局，写「第二年」。

## 六、人名：闽南规矩

- **男**：金城、天送、清海、永福、建平、志明、进财、火旺、文良、阿狮、阿彬。
- **女**：秀缎、秀珠、美玉、惠兰、阿珍、美英、阿娥。
- **土名/绰号**（极重要，一出场就有地方味）：阿肥、臭弟、阿矮明、乌鬼良、菜旺（怣，憨）、阿坏、三黑。
- **称呼**：头家（老板）、厝边（邻居）、少年家、后生家、番客（华侨）、师傅。
- **口语**：无彩（白费）、有影（真的）、歹势（不好意思）、加减做（将就做）、卡紧（快点）、真赞、透早（清早）、暗时（晚上）、生理（生意）、赚食（谋生）、走闯（闯荡）。
- **禁忌**：「梓萱」「子豪」这类北方爆款名，本地长辈一听就知道不是自己人。名字起完用闽南语念三遍，别出谐音笑话。

## 七、三条自律（不能破）

1. 不写真人真事，认得出就改到认不出。
2. 不借小说卖东西。
3. **不写一夜暴富**。爽要爽在「手艺能换钱」，不靠中彩票、不靠天降贵人、不靠无脑反派。反派的失败必须是他自己不懂行。
